아직도 맥스로
블로그 하세요?

맥스는 양을 사는 거고, 머리는 프로와 같습니다. 블로그는 프로로 충분합니다. 계정 1개로 시작해서, 모자랄 때만 1개 더.

1. 먼저 알 것 2026년 11월 기준

모델(머리)은 프로·맥스 모두 같습니다. 맥스는 한도가 크고 새 기능을 먼저 받는 것. 가격은 바뀌니 결제 전에 claude.com/pricing에서 확인하세요.

블로그 하루 1~3편이면 프로 1개로 시작.

5시간 한도가 자주 차면 그때 계정 1개 추가 ($40에 2배). 맥스 5배는 하루 종일 코딩·앱 만들 때나 생각하세요.

2. 맥스처럼 쓰는 설정

1
모델: Opus 5.5
대화창 보내기 버튼 옆 모델 이름 누르기 → Opus 5.5 선택
2
생각 깊이(노력): 중간
같은 메뉴에서 "노력(Effort)" → 중간. Opus 5.5는 원래 중간이 기본값이고, 블로그 글·조사·정리는 중간이면 다 됩니다.
  • 막히거나 복잡한 앱 설계 → 그때만 높음
  • 제목 20개 뽑기 같은 단순 반복 → 낮음 (한도 아낌)
  • 최고 단계는 한도를 많이 먹습니다. 블로그엔 필요 없음
3
코드 실행 켜기
claude.ai → 설정 → 기능 → 코드 실행. 이게 꺼져 있으면 딸깍 스킬이 안 돕니다.
4
딸깍 스킬 올리기
claude.ai → 커스터마이즈 → 스킬 → 올리기. 처음엔 딸깍 자동, 블로그 글 쓰기 두 개면 충분.

3. 한도 아끼는 습관 5개

  1. 한 대화엔 한 가지 일. 글 하나 끝나면 새 대화.
  2. 길어지면 갈아타기. "딸깍 인계 메모 만들어줘" → 새 대화에 붙여넣기. 긴 대화는 한 마디에도 한도를 많이 먹습니다.
  3. 설명 반복 금지. 매번 쓰는 규칙은 스킬에 넣어 두면 다시 말할 필요 없음.
  4. 초벌은 다른 AI. 제목 뽑기·요약 같은 건 "딸깍 다른 AI 지시서"로 무료 AI에 넘기고, 클로드는 검수만.
  5. 노력은 기본 중간. 올리는 건 막혔을 때만.

4. 계정 1개 → 2개

계정 1개일 때
  • 블로그·앱 다 한 계정에서. 위 습관 5개만 지켜도 하루 몇 편은 됩니다.
계정 2개로 늘릴 때
  1. 클로드 앱 설정 → 계정 추가 (다른 이메일)
  2. 역할 나누기: 계정 1 = 블로그, 계정 2 = 앱·코딩
  3. 스킬은 계정마다 따로 올려야 합니다 (한 계정에 올린 건 다른 계정에 안 따라감)
  4. 한 계정 5시간 한도가 차면 인계 메모 들고 다른 계정으로
  5. 남은 한도는 클로드 설정 → 사용량에서 확인
