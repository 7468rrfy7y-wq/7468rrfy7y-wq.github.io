# 딸깍 (DDALGGAK) — 클로드 스킬 모음

코딩 몰라도 한글로 말하면 클로드가 끝까지 해주는 스킬 모음.

**받는 곳: https://7468rrfy7y-wq.github.io/ddalggak/**

## 설치 방법

1. 위 딸깍 페이지에서 필요한 스킬을 **하나씩** 받기 (zip)
2. claude.ai → 설정 → 기능에서 **코드 실행** 켜기
3. claude.ai → 커스터마이즈 → 스킬 → **올리기** → 받은 zip 선택
4. 끝. 스킬은 계정에 붙어서 폰·PC 어디서든 똑같이 동작

> Pro · Max 등 유료 요금제와 코드 실행이 켜져 있어야 스킬을 올릴 수 있음.

## 폴더 구조

```
ddalggak/
├─ index.html     딸깍 페이지 (스킬 받는 곳)
├─ setup.html     준비 안내
├─ skills.json    스킬 목록·버전 (딸깍 앱이 읽음)
└─ skills/        스킬 zip 14개
```

`skills.json`의 버전이 바뀌면 딸깍 앱에 "새 버전" 표시가 뜸.
